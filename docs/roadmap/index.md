# Roadmap

## Current Foundation

- Minimal Cobra CLI
- Version metadata package
- Default project metadata
- Starter docs, CI, Makefile, and release config stubs

## Pre-1.0 Milestones

- `v0.1.0-dev`: local CLI foundation.
- `v0.2.0`: single URL downloader engine.
- `v0.3.0`: basic terminal progress display.
- `v0.4.0`: batch input and queue model.
- `v0.5.0`: resume, retry, and checksum validation.
- `v0.6.0`: config files and history.
- `v0.7.0`: package release validation.
- `v0.8.0`: self-update preview.
- `v0.9.0`: release candidate hardening.

## v1.0.0

First official stable public installable release.

## Post-1 Feature Packs

Per project policy, `v2.0.0` and later feature-pack releases should contain 3
to 4 major new capabilities.
