# Post-1.0 Feature Packs

After `v1.0.0`, each major release adds 3-4 major capabilities.

## v2.0.0 Queue Power Pack

1. Concurrent downloads with `--concurrent`
2. Queue persistence after exit/crash
3. Retry failed downloads
4. Download history

## v3.0.0 Network Power Pack

1. Proxy support: HTTP, HTTPS, SOCKS5
2. Custom headers, cookies, user-agent
3. Timeout controls
4. Rate limiting

## v4.0.0 Automation Pack

1. JSON event stream with `--json`
2. Report export: JSON, CSV, Markdown
3. Failed downloads export
4. Webhook on completion

## v5.0.0 Manifest Pack

1. `daryaft.yaml` manifest
2. `daryaft.lock` lockfile
3. Verify mode
4. Config profiles

## v6.0.0 Inspect and Smart Mode Pack

1. `inspect` / preflight
2. `--dry-run`
3. Smart conflict handling
4. Duplicate detection

## v7.0.0 Segmented Download Pack

1. Segmented downloads
2. Smart resume validation using ETag and Last-Modified
3. Metadata sidecar files
4. Repair mode

## v8.0.0 Mirror and Crawl Pack

1. Mirror fallback
2. Metalink support
3. Limited crawl
4. Extension and size filters

## v9.0.0 System Integration Pack

1. Desktop notifications
2. Open/reveal after download
3. Shell completion
4. Man page

## v10.0.0 Security and Validation Pack

1. Manual checksum verification
2. `hash` command
3. ClamAV / `clamscan` integration
4. File type validation

## v11.0.0 Theme and Accessibility Pack

1. Theme system
2. Custom theme file
3. No-color and no-animation modes
4. Terminal capability detection and `doctor`

## v12.0.0 Advanced Input Pack

1. Clipboard import
2. Extract URLs from text
3. CSV/JSON input
4. aria2-compatible input
