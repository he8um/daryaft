# Daryaft v1.12.0 — TUI Download Input UX Polish

## Status

Implementation scope.

## In scope

- Exported `download.ValidateURL` wrapper around the existing internal validator
- TUI-layer pre-validation for URL input: empty URL and invalid scheme/host caught before plan building, with actionable guidance messages
- TUI-layer pre-validation for file path input: empty path caught with absolute path example hint
- Defaults preview line on URL and file input screens (save directory, retries, resume flag)
- Updated URL input prompt to mention `https://` and `http://` schemes explicitly
- Updated file input prompt to mention absolute path and one-URL-per-line format
- Updated Help screen to mention the `c` shortcut for Settings
- Tests for all new validation paths, guidance messages, defaults preview, updated prompts, and error clearing
- Documentation and manual QA updates

## Out of scope

- Config editing, config set/reset from TUI
- Credential entry in TUI
- Queue or session persistence
- Proxy, auth header, or cookie input
- File picker, path autocomplete, mouse support, clipboard integration
- Changes to downloader retry, resume, or checksum behavior
- New Go dependencies
- Release notes, Homebrew formula changes
- Windows support
