# v1.2.0 — Update UX Polish and Install-Channel Hardening

## Release Intent

```text
v1.2.0 = update UX polish and install-channel hardening
```

v1.2.0 is a focused polish sprint on the `daryaft update --check` feature
shipped in v1.1.0. It improves output clarity, hardens install-channel
detection, adds per-channel upgrade guidance, and strengthens test coverage.
The command remains read-only throughout.

## In Scope

- Improve `daryaft update --check` human output:
  - Release URL shown in all status modes (not only when update is available).
  - Per-channel update guidance (`homebrew`, `goreleaser`, `source`, `unknown`).
  - Clear "A new version is available" notice when an update is detected.
  - Deterministic, testable output structure.
- Improve JSON output contract:
  - All fields present, including empty strings (`""`), never omitted.
  - Boolean fields are real JSON booleans.
  - `update_command` reflects the correct channel guidance.
- Harden install-channel detection:
  - `source` BuiltBy → `ChannelSource` (fast path, no path check needed).
  - `goreleaser` BuiltBy + Homebrew Cellar path → `ChannelHomebrew`.
  - `goreleaser` BuiltBy + non-Homebrew path → `ChannelGoreleaser`.
  - Unknown BuiltBy + non-Homebrew path → `ChannelUnknown`.
  - `brew --prefix daryaft` fallback for symlinked installs.
  - Tests use injected executable-path and brew-prefix functions; no dependency
    on the developer machine's real Homebrew state.
- Per-channel update guidance logic:

  | Install channel | Guidance |
  |----------------|----------|
  | `homebrew`     | `brew update && brew upgrade daryaft` |
  | `goreleaser`   | Download the latest release archive from the GitHub release URL |
  | `source`       | Pull the repository and rebuild: `git pull && go build .` |
  | `unknown`      | Download the latest release from the GitHub release URL |

- Add `result_test.go` with comprehensive tests:
  - `Format()` for all status modes (up-to-date, update-available, dev-build).
  - `updateCommand()` for all four channels.
  - `detectInstallChannel()` for Cellar paths, non-Homebrew paths, BuiltBy values,
    executable error, brew-prefix fallback.
  - JSON contract (all fields present, booleans are booleans, empty strings present).
  - `Status()` precedence.
- Add manual QA checklist: `docs/operations/update-check-qa.md`.
- Update documentation:
  - `docs/command-reference.md` — `update` command section.
  - `docs/usage.md` — update section.
  - `docs/roadmap/self-update.md` — current state reflects v1.2.0.
  - `CHANGELOG.md` — v1.2.0 entry.
  - `README.md` — update check guidance.

## Out of Scope

- Auto-update — not implemented. `daryaft update` without `--check` continues
  to exit non-zero with a clear message.
- Binary replacement of any kind.
- Proxy, custom headers, or authentication support.
- Download queue or history.
- Segmented or concurrent downloads.
- Package-manager automation beyond the existing `scripts/update-homebrew-formula.sh`
  helper.
- TUI update screen — future work.
- GoReleaser `brews:` publishing — remains disabled.

## Future Track

Proxy, custom headers, and authentication support are planned as **Option B**
after this polish sprint. That work begins only after v1.2.0 is released and
the update check UX is trusted.
