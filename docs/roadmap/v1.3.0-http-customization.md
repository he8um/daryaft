# v1.3.0 — HTTP Request Customization

## Scope

v1.3.0 adds HTTP request customization to the Daryaft CLI download and inspect flows.

### In Scope

- `--proxy <url>` — HTTP or HTTPS proxy (no SOCKS5)
- `--header "Name: Value"` — repeatable custom request headers
- `--user-agent <value>` — user-agent override
- `--username` / `--password` — HTTP Basic Auth
- Applied to: root URL download mode, `download` subcommand, `inspect` subcommand
- Full input validation (proxy scheme, header syntax, auth consistency)
- Dry-run and verbose output with safe redaction (`[REDACTED]` for passwords and sensitive headers)
- Unit tests for all validation paths, redaction, request application, and proxy transport
- CLI integration tests via `httptest.Server`
- Docs: feature guide, QA checklist, roadmap scope doc, updated command reference

### Out of Scope

- TUI HTTP auth/config flow
- SOCKS5 proxy support (requires external dependency)
- OAuth or token manager
- Cookie jar or session persistence
- Credential storage (keychain, env file, config file)
- `.netrc` support
- Auto-update
- GoReleaser Homebrew publishing
- Package-manager automation
