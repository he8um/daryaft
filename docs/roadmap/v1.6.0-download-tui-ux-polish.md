# v1.6.0 — Download UX + TUI Queue UX Polish

## Scope

v1.6.0 focuses on CLI download output clarity and TUI batch execution visibility.

### In scope

- Clearer CLI completion message: size and elapsed time
- In-band CLI failure message (`Failed:` prefix)
- Distinct CLI prefixes for `Resuming:` and `Restarting:`
- Batch summary uses `Not started` for items that never ran
- TUI batch execution shows per-item queue history
- TUI queue item status markers: ✓ completed, ✗ failed/cancelled, → in-progress
- No-color mode: ASCII markers `[ok]`, `[!]`, `[>]`, `[-]`
- TUI post-run hint: `enter/h new download • q quit`
- TUI summary: `Not started` label

### Out of scope

- Auto-update
- OAuth/token manager
- Cookie jar/session persistence
- Credential storage
- `.netrc` support
- TUI auth flow
- SOCKS5 proxy
- Config persistence
- Checksum verification
- Concurrent batch download
- Release automation
- New external dependencies
