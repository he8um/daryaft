# Daryaft v1.7.0 — Checksum Verification

## Scope

v1.7.0 delivers CLI checksum verification for single-target downloads.

### In scope

- `--checksum algorithm:hex` flag on `daryaft download` and root URL mode.
- SHA-256 and SHA-512 verification after download completion.
- Checksum format validation before network request.
- Clear mismatch error including expected and actual digest.
- Dry-run checksum display.
- Batch rejection with clear error.
- Root URL mode routing when `--checksum` is passed.
- Internal `checksum` package with `Parse`, `ComputeFile`, `VerifyFile`, `SupportedAlgorithms`.
- Full test coverage: unit, integration via `httptest.Server`, and manual QA.

### Out of scope

- Checksum manifest files or `.sig`/`.asc` signature verification.
- PGP/GPG verification or supply-chain attestation.
- Per-file batch checksum maps.
- TUI checksum entry UI.
- Automatic checksum URL discovery.
- SHA-1 or MD5 support.
- Config persistence.
- Auto-update, OAuth, credential storage, `.netrc`, SOCKS5.

## Quality gates

- `go test ./...` passes.
- `go build ./...` passes.
- `go test -race ./internal/downloader` passes.
- `go test -race ./internal/tui` passes.
- `make lint` passes.
- `make security` passes.
- `goreleaser check` passes.
- `make rc-check` passes.
- Manual smoke: match, mismatch, dry-run.

## Known limitations

- Per-file batch checksums are not supported.
- TUI checksum entry is not implemented.
- Signature or attestation verification is not implemented.
- Checksum verification confirms integrity against a known digest, not publisher
  authenticity.
